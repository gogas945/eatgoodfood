# eatgoodfood

Telegram-бот для подсчёта КБЖУ и набора массы.

- Пишешь, что съел, с весом (или присылаешь фото), а Claude раскладывает это на продукты и считает калории, белки, жиры и углеводы.
- Показывает, сколько съедено за день и сколько осталось до нормы.
- Напоминает поесть (по умолчанию в 12:00, 17:00 и 21:00). Напоминание можно отложить на 2 часа, тогда сдвигаются и следующие. Есть кнопка «Поел».
- Вечером присылает итог дня, по воскресеньям недельную сводку: где недобрал, по какому нутриенту, как меняется вес и пора ли поднять норму.

## Что нужно

1. **Токен Telegram-бота** от @BotFather (у тебя уже есть).
2. **Ключ Claude API:**
   1. Зайди на https://platform.claude.com и зарегистрируйся.
   2. **Billing**: привяжи карту и пополни баланс. Для одного человека хватит минимальной суммы ($5) примерно на месяц-два.
   3. **API Keys → Create Key**: скопируй ключ (начинается с `sk-ant-`). Он показывается один раз.
   4. Желательно поставить лимит расходов в **Limits**, например $10 в месяц.
   - API работает только из [поддерживаемых стран](https://www.anthropic.com/supported-countries). Если твоя страна не в списке, запускай бота на сервере в поддерживаемой стране.
3. **Компьютер, который работает постоянно.** Бот присылает напоминания, только пока он запущен. Подойдёт VPS за $3–5 в месяц (Ubuntu) или домашний компьютер, который не выключается.

> Никому не показывай токен и ключ и не отправляй их в чаты. Они хранятся только в файле `.env` на сервере.

## Быстрая установка на сервер (Ubuntu)

```bash
git clone -b claude/calorie-tracking-system-ggpgz1 https://github.com/gogas945/eatgoodfood.git /tmp/egf && sudo bash /tmp/egf/deploy/install.sh
```

Скрипт спросит токен бота, ключ Claude и твой Telegram ID (узнать у @userinfobot), установит всё и запустит бота как службу. Повторный запуск `sudo bash /opt/eatgoodfood/deploy/install.sh` обновляет бота.

## Запуск вручную

```bash
git clone https://github.com/gogas945/eatgoodfood.git
cd eatgoodfood
python3 -m venv .venv
source .venv/bin/activate          # на Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # на Windows: copy .env.example .env
```

Открой `.env` и впиши `TELEGRAM_BOT_TOKEN` и `ANTHROPIC_API_KEY`. Потом:

```bash
python -m bot.main
```

Напиши боту `/start`. Он пришлёт твой Telegram ID. Впиши его в `.env` в строку `ALLOWED_USER_ID`, останови бота (Ctrl+C) и запусти снова. После этого бот отвечает только тебе, и чужие люди не смогут тратить твой ключ.

### Чтобы бот работал на сервере постоянно (Linux, systemd)

Создай файл `/etc/systemd/system/eatgoodfood.service` (замени путь `/root/eatgoodfood` на свой):

```ini
[Unit]
Description=eatgoodfood bot
After=network-online.target

[Service]
WorkingDirectory=/root/eatgoodfood
ExecStart=/root/eatgoodfood/.venv/bin/python -m bot.main
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now eatgoodfood
journalctl -u eatgoodfood -f      # смотреть логи
```

## Как пользоваться

| Что сделать | Как |
|---|---|
| Записать еду | `гречка варёная 200 г, куриное бедро 180 г, масло 10 г` |
| Рецепт целиком | `на кастрюлю: курица 1 кг, рис сухой 400 г, морковь 200 г, масло 30 г. Съел 1/4` |
| По фото | фото тарелки или этикетки, лучше с подписью |
| Исправить разбор | ответь на сообщение с разбором: `курица была 250 г` |
| Итоги дня | `/today` |
| Неделя | `/week` |
| Вес | `/weight 78.4` (утром натощак, хотя бы 2–3 раза в неделю) |
| Норма | `/norm` показать, `/norm 3000 160 85 400` задать (ккал Б Ж У) |
| Напоминания | `/reminders`, `/reminders 12:00 17:00 21:00`, `/reminders off` |
| Удалить последнюю запись | `/undo` |

## Норма по умолчанию

Для 78 кг, 178 см, 21 год, зал 3–5 раз в неделю:

- обмен веществ в покое (формула Миффлина–Сан Жеора) около 1790 ккал, с учётом активности около 2780 ккал на поддержание;
- для набора нужно +200…300 ккал сверху, поэтому **3000 ккал**;
- белки **160 г** (≈2 г на кг), жиры **85 г** (≈1,1 г на кг), углеводы **400 г** (остальное).

Ориентир: прибавка **0,2–0,5 кг в неделю**. Недельная сводка сравнивает средний вес с прошлой неделей и подсказывает, когда менять норму. Если 2 недели подряд норма выполняется, а вес стоит, подними калории на 150–200.

## Устройство

```
bot/
  main.py        Telegram: команды, кнопки, планировщик напоминаний
  nutrition.py   запрос к Claude API: текст или фото -> продукты с КБЖУ (JSON)
  reminders.py   расписание напоминаний, откладывание, отметка «поел»
  reports.py     тексты: разбор, день, неделя, советы «как добрать»
  db.py          база SQLite (food.db)
tests/           тесты: pip install -r requirements-dev.txt && pytest
```

Расход на Claude: один разбор стоит около 1–3 центов на модели по умолчанию. Если 5–8 записей в день, выходит примерно $2–5 в месяц. В `.env` можно поставить `CLAUDE_MODEL=claude-haiku-5-5`: так в десятки раз дешевле, но точность немного ниже.
